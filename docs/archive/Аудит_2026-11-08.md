## 1. Итог

1. **Конфигурация структурно здорова**: BSL LS — 0 ошибок; конфигурация в базе побайтово совпадает с репозиторием; смоук 6/6, автопрогон 11/11.
2. **Расширение работоспособно, но неаккуратно**: содержимое в базе совпадает с источником (отличаются только отступы в `Style.xml`), имя стиля не соответствует префиксу расширения, режим совместимости отстаёт от конфигурации на две версии.
3. **Три реальных риска**: мёртвый 1С-слой интерфейса (23 неиспользуемых метода), привычка глотать ошибки в `Попытка` (133 блока, 18 неиспользуемых переменных с текстом ошибки), невозможность внешних запросов к базе — COM-коннектор не зарегистрирован.
4. **Одно наблюдение требует проверки**: страницы отчётов, собранные сразу после автопрогона, показывают даты записей на сутки раньше самого прогона. Проверить не смог из-за п. 3.

## 9. Исправление P1-2 (08.11.2026)

### Что показал запрос

```
ВЫБРАТЬ Стенд, ВерсияПлатформы, Сценарий, ДатаЗамера, МедианаМс, ВремяПрогонов
ИЗ РегистрСведений.ПерфРезультаты УПОРЯДОЧИТЬ ПО Стенд, Сценарий
```

22 записи = 11 сценариев x 2 версии платформы, **при одном и том же имени стенда**
`Komp / 8.3.27.2342 / файловая`:

| Версия платформы | Записей | Дата замера |
|---|---|---|
| 8.3.27.2342 | 11 | 2026-11-08 05:22:12…17 |
| 8.5.4.1306 | 11 | 2026-11-07 20:07:31…20:08:11 |

Гипотеза «`ДатаЗамера` не обновляется при перезаписи по ключу» **опровергнута**:
`ЗаписатьРезультат` пишет по ключу `Стенд + ВерсияПлатформы + Сценарий`
(`ПерфСценарии:994`) и ставит `Запись.ДатаЗамера = ТекущаяДатаСеанса()` (`:1007`) —
свежие записи 8.3.27 датированы временем прогона.

### Две причины

1. **Отчёты не различают версию платформы.** `ЗагрузитьРезультатыВнутр`
   (`ПерфОтчетыHTML:552`) раскладывал все записи в `Соответствие` по ключу
   «Стенд → Сценарий». Записи двух версий при одинаковом стенде перезаписывали друг
   друга, и оставалась та, которую регистр отдал последней (`УПОРЯДОЧИТЬ ПО Стенд,
   Сценарий`; физически — по ключу измерений, где `8.3.27.2342` < `8.5.4.1306`).
   На страницу попадали замеры 8.5.4 от 07.11 20:07.
2. **Имя стенда залипало на первой версии платформы.** `ИмяСтендаДляЗаписи`
   (`ПерфСценарии:1330`) при пустом имени брал имя из регистра `ПерфСтенды`
   (`ИмяСтендаИзРегистра`) без проверки версии. Имя стенда содержит версию
   («ПК / версия / режим»), поэтому прогон на 8.5.4 записывался в стенд «… 8.3.27 …»,
   и различитель сборок (по ТЗ — именно `Стенд`) не различал ничего.

Побочно: маркер `reg-rows:22` — это `КоличествоЗаписейРезультатов` по стенду
(все версии), а не число записей, сделанных прогоном (11).
