# ops — эксплуатация и диагностика

Раздел создан на этапе 3 плана; наполнение — этап 5 (приоритет P1).

Появится `Runbook.md`: досылка очереди вручную, очистка данных и журнала регистрации, разбор
журнала ошибок (`ПерфОшибки`), маркеры автопрогона и обмена, где смотреть состояние каналов.

**Граница:** документы контура (VDS, лаборатория, переносы) сюда не входят — они лежат в
приватной папке `ops\` проекта, вне публичного репозитория.
